# MASTER PROMPT — PEMBUATAN DASHBOARD MONITORING UPJKP

Anda bertindak sebagai **Senior Full-Stack Developer, Data Engineer, dan UI/UX Designer**.

Tugas Anda adalah membangun aplikasi web **“Dashboard Monitoring UPJKP – Urusan Pelayanan Jasa Konsultan”** yang digunakan untuk monitoring kegiatan operasional UPJKP.

Aplikasi harus profesional, mudah digunakan oleh staf administrasi maupun pimpinan, responsive untuk desktop/laptop, memiliki database yang persisten, mendukung upload/link dokumen, reminder otomatis, monitoring progress, penagihan, inventory, dan pelatihan.

# 6. SISTEM DEADLINE 30 HARI

Tanggal Draft Masuk menjadi titik awal perhitungan.

Rumus:

Deadline = Tanggal Draft Masuk + 30 hari

Hitung:

- Hari berjalan
- Hari tersisa
- Persentase waktu
- Deadline
- Status keterlambatan

Kategori:

0–20 hari = HIJAU / AMAN  
21–25 hari = KUNING / PERHATIAN  
26–29 hari = ORANYE / SEGERA SELESAIKAN  
>=30 hari dan belum NET = MERAH / TERLAMBAT  
NET = HIJAU / SELESAI

Jika NET tercapai:

STOP countdown laporan.

Kemudian otomatis buat status:

“NET – SIAP PENAGIHAN”

Jangan menghapus histori checkpoint.
